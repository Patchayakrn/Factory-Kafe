# Officer VB.NET Port

ไฟล์ในโฟลเดอร์นี้เป็นโค้ด VB.NET ที่แปลงจากหน้า Officer ของ SabuySoft เดิม ได้แก่

- `fOfficer.vb` — ค้นหา แสดงรายการ และจัดการข้อมูลพนักงาน
- `fOfficerAddEdit.vb` — เพิ่ม/แก้ไขพนักงาน สิทธิ์สาขา ระดับการเข้าถึง และรหัสผ่าน
- `fOfficerSetLimitSearch.vb` — กำหนดช่วงวันที่ย้อนหลังที่ค้นหาได้
- `fConfirmOfficerBarcode.vb` — ยืนยันบาร์โค้ดพนักงาน

ตอนนี้เพิ่มเป็นไฟล์ภายในโซลูชันเพื่อเก็บพอร์ตต้นฉบับ โดยยังไม่ผูก Compile กับ `Coffee_SMH2.vbproj` เพราะโค้ดเดิมใช้ `Janus.Windows.GridEX`, `MyClass` และฟอร์ม/คลาสของ SabuySoft ที่ไม่มีในโปรเจกต์ Coffee ปัจจุบัน การนำไปใช้งานจริงต้องปรับให้ใช้ `DataGridView` และโมดูลฐานข้อมูล/สิทธิ์ของโปรเจกต์นี้ก่อน
