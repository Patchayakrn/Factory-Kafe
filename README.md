# Factory-Kafe

ระบบ Coffee Cafe / Factory Kafe พัฒนาด้วย VB.NET Windows Forms และ .NET Framework 4.8

## การใช้งาน

1. เปิด `Coffee_SMH2.vbproj` ด้วย Visual Studio 2022 หรือใหม่กว่า
2. ตั้งค่า SQL Server ใน `App.config` ตามเครื่องที่จะใช้งาน
3. Restore NuGet packages แล้ว Build แบบ `Release`

ไฟล์ build และไฟล์ฐานข้อมูลสำรองไม่ได้รวมไว้ใน repository เพื่อป้องกันไฟล์ขนาดใหญ่และข้อมูลภายในเครื่อง
